# Banner

A card on Home for unfinished work, with a chevron or an action at the right.

- Continue/finish an import: "Continue importing **Lesson 4**" / "Finish reviewing **Lesson 4**" (an unnamed import shows its date), the whole card a link, chevron-right in `muted`.
- Details pending (`PendingDetails`): "N words without details yet" with a 13 px `muted` second line and **Add details** as a small button that never wraps; turns `success` when done. Only for an account with AI.
- An **error box** in the same place uses `danger-soft` + `danger` with a small Try again button.
