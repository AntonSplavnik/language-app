# EmptyState

What an empty list says (My words tabs, a search with no match): centred, a 64 px rounded icon square (`surface` + `border`, book icon in `muted`), a bold first line in `text`, the explanation in 15 px `muted`, then any action.

- Say what belongs here and how it gets here ("A word counts as learned after 3 right answers in a row."). The Learning tab offers New import; a search with matches elsewhere links "2 in Ignored ›", and so does a filter's empty tab ("No learned words from this import.", "… in this theme.", "… in this group."). A group without any words says "No words in this group yet." over "Use Select to add some." (M13.2).
